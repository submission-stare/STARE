# STARE: Statistical Testing of Algorithmic Robustness in Evaluation

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)
[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)

**STARE** is an open-source framework for evaluating AI trading agents with statistical rigor. It compares DRL algorithms (A2C, PPO, DDPG, TD3) and LLM-based strategists using **Probabilistic Sharpe Ratio (PSR)**, **Deflated Sharpe Ratio (DSR)**, and multi-seed bootstrap confidence intervals — so you can tell genuine performance from lucky backtests.

---

## 1. Installation

Supported Python versions: 3.10 to 3.13 (Python 3.14 is not supported by a dependency stack that includes numba).

```bash
git clone https://github.com/submission-stare/STARE.git && cd STARE
conda create -n stare python=3.12 -y
conda activate stare
pip install -e .
```


This installs STARE as a package so all imports work from anywhere (notebooks, scripts, etc.).

## 2. Run Your First Experiment

Each experiment is just two files: `run.py` + `config.yaml`.

```bash
python experiments/neurips2026_turb/run.py
```

This trains **4 DRL agents** (A2C, PPO, DDPG, TD3) on DJIA-30 stocks (2009–2015), evaluates them on the test period (2019–2020) with a turbulence filter, and saves results with PSR/DSR metrics.

### Three Scenarios Included

| Scenario | Directory | What changes |
|----------|-----------|-------------|
| **turb** | `experiments/neurips2026_turb/` | Turbulence filter ON (`threshold=200`) |
| **noturb** | `experiments/neurips2026_noturb/` | Turbulence filter OFF (`threshold=1e5`) |
| **synth** | `experiments/neurips2026_synth/` | Test data = causal synthetic CSV (zero look-ahead bias) |

All share: DJIA-30 tickers, 1M training timesteps, Optuna-tuned hyperparameters.

The **synth** scenario uses counterfactual synthetic data generated by an external causal SDE pipeline (outside this repository). The CSV is automatically downloaded from a [public S3 bucket](https://anonymous-submission--0-public.s3.us-east-1.amazonaws.com/csde-output-1/csde-1.csv) and cached locally.

## 3. Understanding `config.yaml`

Everything is driven by the config. Here's a trimmed example:

```yaml
# Which agents to train
agents: [a2c, ppo, ddpg, td3]

# Hyperparameters (Optuna-tuned)
ppo_params:
  learning_rate: 1.3e-05
  n_steps: 512
  gamma: 0.95
  clip_range: 0.1
  batch_size: 128

# Training
timesteps_per_model: 1000000

# Data & dates
ticker_preset: "djia_2019"
train_start: '2009-01-01'
train_end: '2015-12-31'
test_start: '2019-01-01'
test_end: '2020-12-31'

# Environment
turbulence_threshold: 200.0

# Benchmark (buy-and-hold for PSR calculation)
benchmark_source: "equal_weight"
```

To change what runs, just edit the config. Want only PPO and TD3? Set `agents: [ppo, td3]`.

## 4. Understanding `run.py`

The run script is intentionally flat — no functions, no classes. It's a template you can copy:

```python
import os, yaml
from evaluation.experiment_setup import build_envs, materialize_drl_kwargs, compute_benchmark_series
from evaluation.multiseed import AGENT_CLASSES
from evaluation.runner import evaluate_agent
from evaluation.reporting import save_experiment_results

HERE = os.path.dirname(os.path.abspath(__file__))
with open(os.path.join(HERE, "config.yaml")) as f:
    config = yaml.safe_load(f)

train_env, test_env = build_envs(config, base_dir=HERE)
n_assets = train_env.action_space.shape[0]

results = {}
for agent_key in config["agents"]:
    cls = AGENT_CLASSES[agent_key]
    kwargs = materialize_drl_kwargs(agent_key, config.get(f"{agent_key}_params", {}), n_assets)
    results[agent_key.upper()] = evaluate_agent(
        cls, agent_key.upper(), train_env, test_env, config["timesteps_per_model"],
        model_kwargs=kwargs,
    )

benchmark = compute_benchmark_series(config, base_dir=HERE)
save_experiment_results(results, os.path.join(HERE, "results.txt"), "My Experiment",
                        benchmark_series=benchmark)
```

## 5. Create Your Own Experiment

```bash
python scaffold_experiment.py my_experiment
# Creates: experiments/my_experiment/config.yaml + run.py
```

Edit `config.yaml` to set your tickers, dates, and hyperparameters, then run:

```bash
python experiments/my_experiment/run.py
```

## 6. Multi-Seed Robustness

A single run doesn't prove anything. Run multiple seeds for statistical significance:

```bash
# 10 seeds × 4 agents on the turbulence scenario
python -m evaluation.multiseed \
    --config experiments/neurips2026_turb/config.yaml \
    --seeds 10 --agent all
```

Then generate LaTeX tables, boxplots, and pairwise statistical tests:

```bash
python -m evaluation.analyze_multiseed --input-dir results/multi_seed
```

## 7. Statistical Metrics

STARE goes beyond simple Sharpe Ratio:

| Metric | What it measures |
|--------|-----------------|
| **PSR** | P(SR\_agent > SR\_benchmark) — corrected for skewness and kurtosis. Benchmark = buy-and-hold. |
| **DSR** | PSR deflated for trial multiplicity (Optuna trials). Penalizes hyperparameter overfitting. |
| **MinTRL** | Minimum track-record length to certify SR at 95% confidence. |
| **Bootstrap 95% CI** | Non-parametric confidence intervals over 10,000 resamples across seeds. |
